# Mastermind

My final project for my 11th-grade app design class in 2021: a recreation of the board game Mastermind, written in Lua for Codea on the iPad.

Guess the hidden four-color code in 12 attempts. Red pegs indicate a correct color in the correct position; white pegs indicate a correct color in a different position.

Each Lua file corresponds to a separate tab in the original Codea project. The game was designed for an iPad in landscape orientation.
